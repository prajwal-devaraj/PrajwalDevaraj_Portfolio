# Prajwal Devaraj — Digital Lab Portfolio

A personal computer-science portfolio built to show **who I am and what I explore**, rather than imitate a résumé or job-application site.

## Design direction
- Futuristic CS / digital-lab visual language
- Animated orbit system, binary canvas, cursor glow, skill ticker, reveal transitions
- Full project archive with search and category filters
- Research lab, journey timeline, education, profiles, and personal identity sections
- Dark/light theme and reduced-motion accessibility
- No extra animation library required

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
```bash
npm run deploy
```

The Vite base path remains `/PrajwalDevaraj_Portfolio/`.
