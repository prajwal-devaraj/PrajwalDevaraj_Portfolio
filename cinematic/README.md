# Prajwal Devaraj — Digital Lab / Complete Profile

A personal portfolio designed to show the complete person, not only a technical résumé.

## What is inside

- Animated hero with rotating identity text and orbital CS/AI visual
- About Me story
- Profile + Contact section directly after About
- Personal identity facts, languages, sports, creative interests, and roots
- Beyond Tech section: writing, teaching, leadership, acting/debate, sports, multilingual identity
- Research Lab
- Searchable/filterable archive of 45+ projects and experiments
- Skills / technical toolbox
- Full experience journey, including engineering, research, teaching, campus work, service, leadership, administration, and internships
- Milestones and recognitions
- Education + coursework
- GitHub, LinkedIn, Hugging Face, Google Scholar, ORCID, X, Linktree, Discord
- Dark/light mode
- Matrix background, cursor glow, holographic profile card, orbit animations, marquees, reveal animations, floating skill chips, animated status signals, and reduced-motion accessibility

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

The Vite base path is already configured for:

`/PrajwalDevaraj_Portfolio/`

## Updating content

Most content lives in `src/PrajwalPortfolio.jsx` in these arrays/objects:

- `profile`
- `experiences`
- `research`
- `projects`
- `skillCloud`
- `studies`
- `identityFacts`
- `languages`
- `humanSide`
- `achievements`
- `socials`

This makes it easy to keep the site current without restructuring the UI.
